# 仮説・反証・実験設計

- 問い、候補仮説、既知の根拠、未確認の前提を分ける。成功を示す観測だけでなく、何が出れば棄却・保留するかを実験前に決める。
- 複数案がある場合、まず最小費用で候補を区別できる実験を選ぶ。ベースライン、入力、指標、反復回数と理由、精度条件、比較可能な環境を定める。実行できない条件を実測扱いにしない。
- 計画専任は既存の計画欄へ記し、許可された実作業担当が実行前の設定・版を保存する。新しい計算資源・範囲・科学的許容条件を勝手に追加しない。
- 結果を見てから判定条件を変えたら、元の条件・変更理由・探索的な判断であることを残す。都合のよい試行だけを抜き出さず、否定結果・失敗・不確実性も残す。
- 出力は仮説→判別実験→採否条件→観測→判断の短い対応。科学的な方法と結果はTeX、機械可読な設定・測定は別ファイル。次の実験を行う理由がなければ止めるが、必須の検証は省略しない。
- レビューは手法が仮説を本当に区別できるか、代替説明・交絡・条件の後付けを検査する。読み取り専用担当は実験や書き込みを行わない。
