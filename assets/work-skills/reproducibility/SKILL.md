# 第三者による再現確認

- 必要なソース、入力または取得手順、依存環境、乱数種、コマンド、期待結果・許容差をパスと版付きで揃える。元担当の会話、シェル履歴、未保存ファイル、秘密のローカルパスへの依存を探す。
- 権限と資源の範囲で、既存成果を壊さない分離した一時出力先から、代表的なビルド→実行→集計→図表/PDF生成を再現する。高額な全実験を自動で再実行せず、代表ケースと未実施範囲を明示する。
- 新しいインストール、外部送信、別環境・長時間ジョブが必要なら既存の権限を確認する。既存の成果を消してクリーン環境を作らない。
- 独立レビュー担当は読み取り専用のまま手順・証拠を検査し、書き込みを伴う再現実行はハーネスの書き込み担当へ差し戻す。自分でエージェントやジョブを起動しない。
- 再現できた範囲、入力/コード/環境の版、検証結果、差異と未実施事項を記録する。コマンドが終了したことだけで数値一致や科学的妥当性を保証しない。
- 実行可能な再現手順と必要な科学的条件は成果物に含める。担当やプロバイダーなどの管理情報は主題のPDFへ載せない。
