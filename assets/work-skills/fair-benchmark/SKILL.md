# 公正な性能・精度評価

- 正しさと必要精度を確認した同じ処理・入力で比較する。版、コンパイラとフラグ、ライブラリ、機器、並列配置、入力規模、精度、乱数種を保存する。
- GPU等の非同期実行は同期点を明示する。ウォームアップ、初期化、キャッシュ、電力/負荷変動を考慮し、測定順と反復回数を理由付きで決める。最小値だけで優位性を断定しない。
- 生測定を保持し、中央値等の代表値とばらつき、失敗数を報告する。外れ値除去は条件と理由を事前に示すか探索的変更と明示する。差がノイズ以下なら判定保留とする。
- カーネル、転送、通信、I/O、前処理を分け、最終的な全体時間も示す。同等でない条件は比較不能と明示し、スケーリングや未測定構成を推測で埋めない。
- 精度は絶対/相対誤差、ゼロ近傍、NaN/Inf、必要な保存量・境界条件を確認する。問題依存の許容差を勝手に緩めない。
- 登録された実行環境・資源上限内で測定する。ログインノードの重い計算は禁止されていれば行わない。外部手配や大規模ジョブをこのスキルだけで許可しない。
- 第三者レビューは測定スクリプトの計時範囲・同期・比較条件と生データからの集計を点検する。新しい実行権限は与えない。
