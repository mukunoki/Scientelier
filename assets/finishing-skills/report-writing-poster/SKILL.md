# ポスター

[共通ルール](../de-ai-style/SKILL.md)に加えて適用する。論文をそのまま縮小して配置しない。

- 指定された用紙サイズ・縦横・テンプレートに従う。中心の問い→根拠となる図表→結論を短時間で追えるよう、領域の主張・見出し・配置を揃える。
- 本文は図の理解に必要な説明に絞り、定義・条件を該当図の近くに置く。別領域を往復しないと読めない構成を避ける。
- 閲覧距離を想定し、文字を小さくして詰め込まない。図・凡例・単位・説明を対応づけ、色だけで区別しない。
- 最終確認では全体の情報量・余白・読順と、実際の印刷サイズでの文字・図の可読性を点検する。未確認の印刷条件は管理結果に明示する。
