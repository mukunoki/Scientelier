This is an adapted skill, not an unmodified upstream installation. It condenses the 34 editing patterns and two-pass draft/audit workflow, adds Japanese academic editing guidance, and integrates with Agent Harness's existing scientific-fidelity, bibliography, TeX/PDF and independent-review rules. The instructions are self-contained inside the captured writing-rules snapshot; remote agents do not need to download upstream resources.

Author-specific medical voice calibration, detector-score optimization, numerical sentence-length targets and unconditional word/punctuation bans are not carried over. Scientific terminology, quotation typography and publication rules take precedence over stylistic substitutions. The upstream medical-paper example passages (credited there to a CC-BY-4.0 article) are not reproduced here. Existing user common/paper overrides and previously pinned run snapshots are not rewritten.
