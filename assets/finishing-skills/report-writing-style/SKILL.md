# 表現・文体 — AIらしい表現を避ける

全媒体の新規執筆・追記・修正と最終推敲で[共通ルール](../de-ai-style/SKILL.md)と併用する。

目的は読者の理解と科学的な正確さであり、AI検出器の回避や作成過程の偽装ではない。内容のない定型表現は執筆段階から入れず、共通の内容保持を守って推敲する。表現改善の助言が、既存の内容保持・専門用語・媒体の文体や指定様式と衝突する場合は、既存のルールを優先する。例示する語はAI専用の語でも、生成元を判定する根拠でもない。禁止語リストや自動一括置換にしない。スライド・ポスターの短文を論文調に引き延ばさない。

執筆時と最終推敲、独立・敵対レビューで、不要な定型表現を確認する。検査スクリプトは前後の文脈付きの候補抽出までとし、単語の出現やAIらしさの点数だけで不合格にしない。言い換えは原文と根拠を読んで採否を決め、単純な同義語への置換で済ませない。主張とその比重、断定の強さ、文の働きも確認し、評価を目標、説明を依頼、予定を実施済みの報告へ変えない。適切な文は変更せず、語尾や警告数を減らすためだけの修正を繰り返さない。変更の確認は共通ルールの差分・全文・生成物の点検で行い、別の採点工程や提出形式は追加しない。

## 日本語

### 文の関係と対象

- 文ごとに主語・述語・対象を確認する。英語の語順や無生物主語を直訳せず、助詞「は／が／も／で」も選び直す。「これ／それ／片方」は参照先が追いにくい場合だけ具体的な語に戻し、原文・前後の文・根拠にない主体や対象を推測で補わない。名詞の積み重ね、独自の短縮語、長い連体修飾、「〜を行うことが可能である」等の重なりを整理する。専門語や無生物主語を一律に排除せず、口語調にも変えない。
- 修飾語、条件・例外・否定・限定・数量がどの動作や判断にかかるか確認する。長文の分割、段落の統合、ダッシュの除去で、理由や条件の適用範囲、因果・手段・目的の向き、並列関係を変えない。段落は話題のまとまりで区切り、関連を保てる場合だけ文を分ける。文字数や読点数に合わせるためだけに分割・結合しない。
- 文末は事実・結果の説明、評価、提案、依頼、予定を区別して選ぶ。事実を呼びかけに、推奨を義務や実施予定に変えず、動作主や文の働きが明瞭な原文は保つ。媒体や投稿先の指定を優先し、常体・敬体の変更指定がなければ適切な原文の文体を維持する。

### 定型表現・比喩・論理

- 「重要な役割」「革新的」「包括的」「画期的」「不可欠」「重要な転換点」「新たな可能性を切り開く」「シームレス」等の空疎な強調は削るか、確認済みの結果・比較条件に即して具体化する。最適化・フレームワーク等の正式な専門語は残す。「有意」は統計的意味と区別する。「示唆」を「実証」に変えず、「約」「わずかに」等の情報を持つ修飾は残す。
- 「多くの研究が示している」「専門家によると」等の帰属のない一般論は、具体的な一次資料と該当する主張を示す。出典や具体例を創作して埋めない。
- 「また／さらに／一方で／すなわち／以上より」は本当に追加・対比・説明・結論を表すか確認する。単なる話題変更を対比にせず、必要な接続まで一律に削らない。「可能性があると考えられる」等の重なる留保は整理しても、不確実性や断定の強さを変えない。
- 「結論から言うと」「以下の観点から見ていきましょう」「今後の発展に期待したい」等の中身のない前置き・締めは、内容に即した主張・限界へ整理する。「重要なのは」等が評価を担う場合は、その評価を述語等に残す。予告を後の内容とまとめる場合も、注目の理由や論理上の役割を落とさない。構成上必要な案内は残す。「ご質問ありがとうございます」「参考になれば幸いです」等のチャットの挨拶は主題の文書に入れない。
- 「単なる〜ではなく〜」「〜にとどまらず〜」の反復、結論を繰り返す段落末、無理な三点列挙を見直す。二重否定・修辞的対比は、意味が同じ場合だけ簡潔にする。「AではなくB」を「AとB」や「AよりB」へ変えず、必要な否定・限定・対比と比重を保つ。規約への適合だけを目的に主観・経験談・脱線を足さない。
- 段落は、その段落で示した結果・解釈・要点を中心に結ぶ。「〜しない」「〜できない」「〜ではない」「〜とみなさない」等の否定や、未確認の但し書きだけで段落を締める定型的な反復を避ける。留保は関連する主張・結果の近くに置き、同じ留保を各段落末へ重ねない。ただし、科学的に必要な否定、反例、成立しなかった結果、限界・未確認事項は明示し、それ自体が段落の要点なら否定で結んでよい。語尾だけを肯定へ置換したり、根拠のない成功・結論を追加したりしない。執筆・最終推敲・独立レビューでは段落全体を読み、結びがその要点を伝えているか確認する。
- 見直し候補は、監査、未達、掃引、効く、瞬間、壊れる、境界、実測、経路、窓、根拠、安全、運用、だけ、まま、その、実際、全部、任せる、記録され、天井、成否、限る、主張、族、群、狙った、鍵、核心、本命など。意味の曖昧な比喩・内輪語として使っていないか確認する。「回す」は実行、「使い回す」は再利用、「載る」は格納・表現・適用のどれかを具体化する。「時間が溶ける」「静かに壊れる」等の擬人化は、分かっている状態・動作・影響を直接書く。原因不明の異常を特定の故障やデータ破損と断定せず、定着した専門的用法は残す。

### 文体・見出し・装飾

- 節のタイトルは文章調にせず内容を明確に示す。対象・条件が識別に必要なら短縮しすぎない。本文を、読点で間を作って助詞句だけで終える広告調へ変えない。スライドの見出しや箇条書きで意味が明瞭な短句は保つ。文長・語尾の数値ノルマを設けず、論文の「である」調など媒体の文体に合わせる。初出の定義・略称の扱いは共通ルールに従う。
- 箇条書き・太字は、手順、条件、列挙や要点の識別に役立つ場合に使い、装飾のための反復・絵文字を控える。箇条書きの割合や太字の件数を固定せず、論文本文とスライド・ポスターで使い分ける。箇条書きを文章へ直して意味や各項目の独立性が失われるなら残す。
- 不要な括弧の補足は文章へ整理するが、略語、数式、引用、範囲、凡例に必要な括弧は残す。ダッシュ「--」で文を挿入しない。文末を飾るだけのコロンや不自然な空白を整えるが、ラベルと値、数値と単位、数式、URL、コード、TeXの組版に必要な区切りは保持する。引用・数式・数値範囲・識別子を一括置換しない。

### 口語・比喩を具体化する言い換え例

対象と意味が一致するときに使う。引用・正式名称・識別子・専門的に定義した用語は保護する。

| 元の表現・文脈 | 言い換え候補 |
| --- | --- |
| 効く | 影響する（何に、どの方向へ影響するかを明示） |
| 浮かび上がらせた | 示した |
| 頭打ちになる／頭打ちの原因 | 超えられない／上限の原因 |
| 動かした（実装を） | 実行した |
| 帯に収まり | 範囲に収まり |
| 〜ほかに方法が無い | 方法は〜に限られる |
| 制約として働く | 制約として作用する |
| 入力に取れる形式／取れる基数 | 受け付ける形式／選べる基数 |
| 採れる方式／採れるか | 選択できる方式／選べるか |
| 縛り（動詞の連用形）／縛り（名詞） | 制約し／制約 |
| 落ちる（クロック・精度・帯域幅・実測値・時間） | 下がる／低下する／短縮する（対象に応じて選択） |
| 整数へ落として扱う | 整数へ変換して扱う |
| 形式に載らない／DRAMに載らない | 表せない／収まらない |
| FP64に届かない／ここまで届く | 達しない／達する（精度・性能等の指標を明示） |
| 上限が〜まで開く | 幅を持つ（上限値の変化なのか、条件による範囲なのかを明示） |
| 外す（探針で工程を外す） | 除く（工程を省略するのか、計測対象から除外するのかを明示） |
| 下がって見える | 見かけ上低くなる |
| 上で見た／上限で見た／代償を見る／上位語だけを見る | 述べた／評価した／評価する／参照する |
| 上限は動かない／421.0 msと動かない | 変わらない（数値・単位・有効桁を保持） |

- 「頭打ち」は観測範囲で増加しなくなっただけなら「増加が鈍化する」「測定範囲ではほぼ一定」とし、理論的に「超えられない」と強めない。「方法は〜に限られる」も代替手段を排除できる条件・根拠がある場合だけ使い、未調査ならその範囲を限定する。
- 「落ちる」は指標を確認する。精度・クロック・帯域幅の低下と実行時間の短縮を混同せず、実測値なら何の測定値かを明示する。整数への変換では丸め・切捨て等の意味を失わない。「変わらない」は表示桁で同値なのか、測定誤差内で差がないのかも区別する。
- 「上限が開く」を「幅を持つ」とすることで上限値の上昇を単なるばらつきに変えない。「帯」は信頼帯・周波数帯等の専門的な意味なら残す。「見た」は文脈に合わせて述べた・評価した・参照した等に具体化し、実際にしていない評価を追加しない。
- 置換件数を達成ノルマにしない。文全体の助詞・活用を整え、変更箇所は共通の再確認手順に従う。

## English・日英対応

- Read English independently, not only against a Japanese gloss. Clarify ambiguous pronouns, noun stacks and long openings that hide the subject. Preserve appropriate active/passive voice and domain-standard terminology; no sentence-length quotas or blanket bans on semicolons.
- Remove unsupported promotion (groundbreaking, pivotal), empty evaluation, ornamental -ing tails, forced triples and repetitive openings only when they obscure or inflate meaning. Keep genuine logical markers, attribution and concise claims. Prefer precise verbs over empty “serves as” constructions; do not invent facts to make prose specific.
- Review delve, comprehensive, landscape, highlight, markedly, underscore, showcasing, intricate, meticulously, crucial, insights, notably and conversational metaphors such as buys, survives, carry or reach in context, including their inflections. When they serve only as decoration or empty evaluation, state what was measured, analyzed or confirmed directly. Preserve technical meanings (arithmetic carry, core, path, family), functional qualifiers, quotations and publication typography. “Significantly” must match the statistical meaning; “was associated with” must not become “caused”.
- Avoid excessive rhetorical em dashes and stacked hedges while retaining warranted uncertainty. Never globally replace punctuation, TeX commands, code/API identifiers, citation keys, authors or official titles. Do not add subjective anecdotes or disrupt sentence patterns just to appear less formulaic. Do not import medical-author-specific word choices into computing texts.
- 日英両版がある場合だけ、主張・条件・数値・単位・用語・図表・文献・限界を同じ変更単位で照合する。正本の言語は作業の指定に従い、英語先行やページ数一致を強制しない。片方の言い回しだけの修正で他方の正しい文を揺らさず、それぞれ自然に書く。単言語文書に翻訳を追加しない。
