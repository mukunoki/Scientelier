# スライド

[共通ルール](../de-ai-style/SKILL.md)に加えて適用する。

- 発表資料は対象読者・発表時間・指定画面比率に合わせ、各ページの要点と問い→根拠→結論の流れを明確にする。詳細は必要に応じてノートや補足へ移すが、主張の条件を隠さない。
- 論文解説モードの自習教材はlesson-storyboardの紙芝居型構成を使う。背景・前提から読むだけで理解できるようにし、発表時間への圧縮や非表示ノートへの説明移動は行わない。ページ数の扱いと段階表示は同スキルに従う。
- 長い論文調の文章を短文と図に整理する。全図の番号付けやfigure環境は一律に要求せず、発表上の参照に必要なものを選ぶ。
- 投影時に読める文字・軸・凡例と十分なコントラストを保ち、文字の縮小で詰め込まない。
- 共通の全ページ確認では、ページ間の流れ・ノートとの矛盾・段階表示の抜けを確認する。
