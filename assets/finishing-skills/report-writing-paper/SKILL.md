# 論文・レポート

[共通ルール](../de-ai-style/SKILL.md)に加えて適用する。説明順序・定義・全文の見直しは共通、図表の数値・文献照合は検証ルールを正本とする。ポスターやスライドにはこの様式を適用しない。

- 標準報告書は同梱の情報処理学会研究報告テンプレートを使う。論文は指定された投稿先・テンプレート・ページ制限に従う。指定がなければページ数に上限を設けず、理解に必要な説明量を優先する。
- 要旨は単独で読めるようにし、課題・方法・主要な結果と主張を成立させる条件を示す。詳しい証明や公開物一覧は本文へ置く。序論は動機と貢献、本文は根拠と再現手順、結論は示せた範囲を担う。
- 付録を含む参照図表には、様式に沿う番号・キャプション・本文からの参照を付ける。付録の同種項目は説明順と記号を揃える。図表の配置を一律に固定せず、読順と組版で判断する。
- 紙面では段組、数式・参考文献・図表の配置と可読性、投稿先のページ制限を確認する。検算メモや口頭説明で本文を代用しない。
