# 公開前の手順

## リポジトリの使い分け

- 公開ソース：`mukunoki/Scientelier`。個人データと以前の非公開履歴を含めない、新しい初期コミットから管理します。
- 開発・旧履歴：`mukunoki/Scientelier_dev`（非公開）。既存のローカル作業フォルダの `origin` はこちらを参照します。フォルダ名やアプリ・データの場所は変更しません。
- 以降の公開更新も同じ `Scientelier` に通常のcommit・pushで反映します。更新ごとに公開リポジトリを作り直しません。開発側で検証し、公開許可リストに通るソースだけを、公開側の独立したcheckoutへ反映してください。

開発側に公開リポジトリへのpush先を追加して、開発履歴ごとpushしないでください。名前変更前の `Scientelier` URLが残る別のcloneがある場合は、pushする前に `Scientelier_dev` へ更新してください。公開版の新しいコミットにはGitHubのnoreplyメールを使い、個人メールの公開を避けます。

## 公開対象

コード・テスト・依存定義、ドキュメント、標準プリセットskills、執筆ルール、オリジナルのTeX/Beamerテンプレート、アイコンです。個人編集ルール、アカウント、SSH先、キー、タスク、作業ログ、論文入力、実験データ・結果、生成PDF、旧アプリ、node_modulesは対象外です。

`.gitignore` は誤追加防止です。既に追跡されたファイルや履歴を消すものではありません。配布処理は別に `scripts/release-files.cjs` の許可リストとGitの追跡一覧を使い、作業フォルダ全体をコピーしません。配布アプリのコンパイル済みコードも追跡されたソースから導出し、残った古いビルド・テストを含めません。

## 旧リポジトリをそのまま公開しない

旧private履歴にはローカル環境のパスと、再配布条件が明示されないIPSJ原配布が記録されています。現在のファイルの整理だけでは過去版は消えません。元の履歴を強制書換えせず、履歴なしの公開用ソースから新しいGit履歴を作る方法を推奨します。リポジトリの公開設定やpush先はユーザーが別途確定してください。

```sh
npm run public:check
npm run public:check -- --history
npm run public:export
```

`public:check` は公開対象の通常ファイルを確認し、高確度の鍵形式、ローカルホーム・プライベート接続IPの混入を値を表示せず検出します。`--history` は全到達可能ブランチのblobも読み取り、除外対象と機密候補を列挙して問題があれば終了コード1です。作者名・メール、コミット文、任意の機密文章・画像、未対応の秘密形式まで保証する検査ではありません。公開前には追加の秘密検査と人による内容確認も行ってください。

`public:export` は `release/source-…/` へ公開対象だけを書き出します。`.git`・コミット作者情報・元履歴を含めず、新規Gitも自動作成しません。既存フォルダへの合成・上書きは禁止です。公開ファイル一覧と除外件数の `PUBLIC_SOURCE_MANIFEST.json` も出力します（Gitの標準除外対象）。除外した個人ファイル名をこの一覧に転載しません。新しいソースは先にレビューしてGitへ追加しなければ書き出されません。Git追加済みでも許可リスト外のファイルは書き出しません。

公開用ディレクトリの内容を確認し、必要なファイルだけを新規リポジトリに記録してください。元のprivateリポジトリの可視性変更・履歴書換え・force pushはこれらのツールで行いません。新しいコミットの作者名・メールを公開してよいかも確認してください。

## 初回インストールの検証

書き出し先で `npm ci`・`npm run build`・`npm test`・`npm run test:distribution` を実行し、`npm run setup` でアプリを作成します。個人データ領域を読まないテストには `SCIENTELIER_DATA_DIR` を使います。本番プロファイルとの同時利用は避けてください。

標準skills・執筆ルールと上流LICENSE/NOTICEは残します。IPSJ原配布だけは[公式取得手順](installation.md)に分離します。MITはScientelierのオリジナル部分・権利者の公開許可がある部分に適用し、[第三者表示](../THIRD_PARTY_NOTICES.md)を削除しません。

## バイナリ配布

`npm run package:mac` で現在のMac CPU向けアプリとZIPを作成します。実行用ファイル一覧・SHA-256はアプリの `Contents/Resources/app/DISTRIBUTION_MANIFEST.json`、依存名・版・ライセンス宣言は `DEPENDENCY_NOTICES.json` に記録します。アプリは個人設定・タスク・実験やIPSJ原配布を含めません。元の開発用アイコンは公開用ではありません。

配布版作成はDeveloper IDの取得、Apple公証、GitHub Releaseへのアップロードを行いません。広い配布前には署名・公証、利用するCPU/OSでの起動・端末・PDF実動確認を別途行ってください。

同梱コード・依存だけのGUI検証は `npm run test:distribution-ui -- /absolute/path/Scientelier.app`。公式Electronのテスト入口で配布物のbootstrapを読み、実CLI検出とネット通信を無効にした新規一時プロファイルで、画面・標準ルール・PTY・PDF描画を確認します。配布アプリの実行ファイルにスクリプト引数を渡してもアプリ本体が起動するため、この検証用コマンドを使用してください。
